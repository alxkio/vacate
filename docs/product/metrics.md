# Product metrics

**Status:** PROPOSED

## North-star outcome

**Weekly active organisations completing a trustworthy leave workflow.**

An organisation counts when, within a rolling seven days, it has at least one submitted request and one final decision or valid auto-approval.

## Early funnel

| Stage | Metric | Initial question |
|---|---|---|
| Acquisition | Qualified design-partner conversations | Can the target buyer be reached repeatedly? |
| Activation | Time from signup to first configured policy | Can an admin self-onboard? |
| First value | Time to first approved request | Does setup create a usable workflow? |
| Engagement | Organisations with weekly leave activity | Does the system replace the existing process? |
| Retention | 30/90-day active organisations | Is leave management recurring value? |
| Trust | Permission defects and balance-correction rate | Is the system safe enough to retain? |

## Open questions

- What event is the billable/activation event: first active employee, approved request, or connected calendar?
- What support burden is acceptable for a self-serve customer?
