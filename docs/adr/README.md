# Architecture decision records

ADRs capture decisions that implementation may rely on and that would be expensive to reverse.

## Required format

```md
# ADR-0001: Short decision title

Status: PROPOSED | ACCEPTED | SUPERSEDED
Date: YYYY-MM-DD
Owner: name/role

## Context

## Decision

## Consequences

## Alternatives considered

## Evidence and links
```
