# Vacate

Vacate is a proposed absence-management SaaS for companies. It aims to make leave rights, requests, approvals, and team availability visible and easy to manage.

## Current product direction — provisional

- Launch sequence proposed so far: Greece, then Norway/Sweden/Denmark/Finland, then Germany/France/Netherlands, then the UK/Spain.
- Initial product: employee leave requests, balances, approvals, and calendar visibility.
- Possible later expansion: equipment, rooms, car pools, holiday homes, and other shared resources. These are **not MVP scope**.
- Proposed differentiators: role-scoped visibility, flexible organisation hierarchy, multi-level approvals, and Microsoft Teams/calendar integration.

> **Important:** This direction is not yet a committed strategy. The existing product, domain, market, and technology documents contain conflicting target segments and geographies. Resolve the open questions in [the product charter](docs/product/product-charter.md) before implementation.
